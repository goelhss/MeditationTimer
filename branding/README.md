# Meditation Timer branding

`meditation-timer-purple-lotus-120.png` is the square 120 × 120 OAuth logo.
It is rendered from `docs/assets/purple-lotus.svg`, which adapts the original
project artwork in `app/src/main/res/drawable/lotus_splash.xml` first committed
with Meditation Timer in commit `ecde7ba`.

No third-party artwork, stock icon, trademark, or Google brand element is used.
The source artwork is distributed with the rest of this repository under the
MIT License.
